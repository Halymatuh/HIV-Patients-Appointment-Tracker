# HIV-Patients-Appointment-Tracker
This is a simple desktop application built with Python Tkinter and a basic Machine Learning model (Logistic Regression) to manage patient records and predict the risk of missed medical appointments.

The system helps simulate how AI can assist in healthcare scheduling by identifying patients who may need reminders or follow-ups.

Features
📝 Add patient records (Name, Age, Appointment Date)
📅 Validate appointment dates
🤖 AI-based risk prediction using Logistic Regression
⚠️ Classifies patients as High Risk or Low Risk
💾 Stores data in a CSV file (patients.csv)
🖥 Simple graphical user interface (GUI) using Tkinter
